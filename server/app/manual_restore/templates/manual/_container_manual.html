Restore manual

Memulihkan seluruh container ke server mana pun dengan satu perintah curl, tanpa runner. Jalur untuk kejadian saat Naikkan ke production tidak bisa dipakai: tidak ada runner, database cadangan belum disiapkan, atau production perlu dipulihkan di server baru. Butuh LumbungDB yang hidup; bila LumbungDB mati, atau perlu pemulihan ke waktu tertentu, satu database, atau akun _users, pakai file di NAS mengikuti README image.
