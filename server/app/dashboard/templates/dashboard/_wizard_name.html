Daftarkan container baru

Harus unik di seluruh LumbungDB, jadi hindari nama umum seperti mariadb. Huruf, angka, _ . -; harus diawali huruf atau angka. Menjadi nama folder di NAS: /lumbungdb/{{ name or "" }}/
{% include "dashboard/_name_check.html" %}
Port MariaDB di server tujuan. Script menolak bila port sudah terpakai.
Pilih runner supaya MariaDB langsung dipasang di mesin runner itu, tanpa menjalankan perintah apa pun. Sesudahnya container bisa di-start, stop, dan restart dari dashboard. User dan password dibuat acak di mesin runner (<SCRATCH_DIR>/containers/<nama>/.env), tidak dikirim ke LumbungDB.

Server tidak perlu diisi. Agen membacanya dari mesin tempat container berjalan dan mengirimnya lewat heartbeat.
