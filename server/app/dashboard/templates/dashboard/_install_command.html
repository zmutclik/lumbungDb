Butuh Docker dan Compose v2, serta akses dari server itu ke LumbungDB. Script membuat password acak di .env di subfolder <project>/ pada folder tempat perintah dijalankan, menjalankan MariaDB, lalu menunggunya sehat. Password tidak dikirim ke LumbungDB.

Pemakaian pertama mengikat perintah ke mesin itu. Bila gagal, jalankan perintah yang sama lagi dari folder yang sama; password tidak berubah. Untuk membaca script lebih dulu: curl -fsSL {{ base_url }}/install.sh -o install.sh; script tidak berisi token.
