Butuh Docker dan Compose v2, akses HTTPS ke LumbungDB, dan kunci privat age runner di /etc/lumbung/age-runner.key (izin 600; lokasi lain: AGE_IDENTITY_FILE=/path sebelum sh). Script memastikan kunci itu salah satu penerima BACKUP_AGE_RECIPIENTS, menulis .env.runner di subfolder lumbung-runner/, lalu menjalankan runner. Scratch bawaan /srv/lumbung-scratch (ubah dengan SCRATCH_DIR=/path).

Pemakaian pertama mengikat perintah ke mesin itu. Bila gagal, jalankan perintah yang sama lagi dari folder yang sama. Untuk membaca script lebih dulu: curl -fsSL {{ base_url }}/install-runner.sh -o install-runner.sh; script tidak berisi token. Pasang di mesin yang bukan server container yang diuji.
